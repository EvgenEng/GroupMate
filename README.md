# GroupMate 🤖

Бот для группы в **Telegram** и сообщества **ВКонтакте** (можно одну сеть, можно обе сразу):
погода по Москве и области, поздравления с днём рождения, приём заказов с уведомлениями менеджерам,
приветствие новичков и ответы нейросети.

Работает бесплатно: погода — [Open-Meteo](https://open-meteo.com) (без ключа),
нейросеть — бесплатный тариф Google Gemini или OpenRouter, ВКонтакте — свой лёгкий клиент Long Poll API.

> Идея и часть подходов вдохновлены ботом [OurMate](https://github.com/Naz1anmak/OurMate).

## Что умеет

| Функция | Как работает |
|---|---|
| 🌅 Погода утром | В 07:00 — прогноз на день: Москва подробно (утро/день/вечер), 4 направления Подмосковья кратко, советы (зонт, гололёд, ветер) |
| 🌙 Погода вечером | Прогноз на завтра в 21:00 — **выключен по умолчанию** (`WEATHER_EVENING_ENABLED=true`, чтобы включить) |
| 🔔 Изменения погоды | Каждые 2 часа (9:00–21:00) сверяет прогноз с утренним: дождь/снег, гроза, ветер, перепад ≥4°, гололёд — без повторов |
| 🎂 Дни рождения | Telegram: `/mybd 15.04`. ВК: «др 15.04» или **автоматически из профиля**, если дата не скрыта. В 10:00 — поздравление (пишет нейросеть, при сбое — шаблон). Админам — напоминание за день |
| 🛍 Заказы | Картинка-прайс → каталог по разделам → корзина (весовые товары — с шагом 0,5 кг) → ФИО → телефон → пожелания → заказ. ФИО и телефон запоминаются для следующих заказов. После заказа бот предлагает указать день рождения (бонус), если его нет в профиле |
| 📣 Менеджеры | Новый заказ приходит указанным людям в Telegram и/или ВК: позиции и количество, сумма, ФИО, телефон, день рождения, комментарий — с кнопками «Принят / Готов / Выполнен / Отменён». Покупателю приходит сообщение о смене статуса |
| 🛒 «Товары» ВК | Заказ, оформленный через раздел «Товары» сообщества, тоже приходит менеджерам |
| 👋 Новички | Приветствие в группе Telegram и беседе ВК с кнопкой «Сделать заказ» |
| 💛 Мягкие напоминания | Раз в неделю (по умолчанию в пятницу) и заранее перед праздниками (`config/holidays.json`) — не чаще раза в день |
| 💬 Нейросеть | В личке — на любое сообщение, в группе/беседе — по упоминанию или ответу боту. Суточный лимит на человека |
| ⚡️ Инлайн (Telegram) | `@бот вопрос?` в любом чате — ответ нейросети; `@бот` без текста — погода и каталог |

Всё, что бот публикует по расписанию, уходит **сразу в обе сети**: в группу Telegram и в беседу ВК.

## Быстрый старт

### 1. Ключи

**Telegram** (если нужен):
1. [@BotFather](https://t.me/BotFather) → `/newbot` → токен.
2. Там же: `/setinline` (инлайн-режим) и `/setprivacy` → Disable (чтобы бот видел слова «погода» в группе).
3. Добавьте бота в группу и **сделайте администратором** (нужно для приветствий).

**ВКонтакте** (если нужен), в веб-версии, будучи администратором сообщества:
1. Управление → Сообщения: «Сообщения сообщества» — **Включены**.
2. Сообщения → Настройки для бота: «Возможности ботов» — **Включены**, галочки «Добавить кнопку „Начать“»
   и «Разрешать добавлять сообщество в беседы».
3. Управление → Работа с API → Ключи доступа → **Создать ключ** (права: управление сообществом, сообщения,
   фотографии, документы, стена, товары). Нужна включённая двухфакторная аутентификация в VK ID.
4. Работа с API → **Long Poll API**: включить, самая новая версия API. Типы событий: «Входящее сообщение»,
   «Действие с сообщением», «Разрешение на получение», «Подписка на сообщество», «Товары → Создание заказа».
5. Добавьте сообщество в беседу и **сделайте администратором беседы** — тогда бот видит команды без упоминания.

**Нейросеть** (бесплатно): ключ [Google AI Studio](https://aistudio.google.com/apikey), запасной —
[OpenRouter](https://openrouter.ai/keys).

### 2. Настройка

```
cp .env.example .env        (Git Bash / Linux / macOS)
copy .env.example .env      (командная строка Windows)
```

Заполните `.env` — каждая строка там подписана. После первого запуска узнайте ID через команду `/id`:
в личке с Telegram-ботом → `OWNER_ID`, в группе Telegram → `GROUP_CHAT_ID`, в беседе ВК → `VK_CHAT_PEER_ID`.

**Менеджеры заказов** — `ORDER_NOTIFY_TG` и `ORDER_NOTIFY_VK`: ID, `@username` или ссылка на профиль,
несколько через запятую. Каждый менеджер должен **один раз** написать боту `/start` в Telegram и написать
сообществу во ВК — иначе боты не смогут ему писать.

### 3. Запуск

**Windows без Docker:** двойной клик по `run.bat` (нужен Python 3.11+).

**Docker:**

```
docker compose up -d --build
docker compose logs -f
```

### 4. Проверка

- Telegram, в личке с ботом (владелец): `/test_morning`, `/test_evening`, `/test_bd`, `/catalog`.
- ВКонтакте, в сообщениях сообщества (администратор из `VK_ADMINS`): `/test_morning`, `/test_bd`, кнопка «🛍 Каталог»,
  в беседе — `/bd_sync` (подтянуть дни рождения участников из профилей).
- Оформите тестовый заказ — менеджерам придёт уведомление с кнопками статусов.

## Настройка под себя

- **Каталог** — `config/catalog.json`: разделы, товары, цены, единицы, шаг (`step`: 0.5 — по полкило), описание магазина.
- **Праздники** — `config/holidays.json` (напоминания заранее — с учётом срока изготовления).
- **Характер бота** — скопируйте `config/prompt.example.txt` в `config/prompt.txt` и опишите.
- **Точки погоды, время рассылок, лимиты, вкл/выкл функций** — в `.env`.

После правки файлов в `config/` перезапустите бота.

## Команды

**Telegram**

| Команда | Кто | Что делает |
|---|---|---|
| `/weather`, «погода» | все | погода на сегодня |
| `/catalog`, `/cart`, `/myorders` | все (в личке) | каталог, корзина, мои заказы |
| `/mybd ДД.ММ`, `/mybd удалить` | все | записать / убрать свой день рождения |
| `/birthdays` | все | ближайшие дни рождения |
| `/orders` | владелец и менеджеры | открытые заказы с кнопками статусов |
| `/bd_add ДД.ММ Имя`, `/bd_list`, `/bd_del ID` | владелец | управление днями рождения |
| `/test_morning`, `/test_evening`, `/test_bd` | владелец | проверка рассылок |
| `/id` | все | ID чата и пользователя |

**ВКонтакте** — кнопки меню в личных сообщениях сообщества, плюс слова: «каталог», «погода»,
«корзина», «мои заказы», «др 15.04», «др удалить», «дни рождения», `/id`.
Менеджерам: «заказы». Администраторам: `/test_morning`, `/test_evening`, `/test_bd`, `/bd_sync`, `/bd_add`, `/bd_list`, `/bd_del`.

## Где хранятся данные

Всё — в одном файле `data/bot.db` (SQLite): заказы, корзины, дни рождения, служебные данные.
Файл не попадает в git (в нём телефоны клиентов) — **делайте резервные копии** сами.
Открыть таблицей можно в бесплатной программе DB Browser for SQLite.

## Структура

```
main.py                 точка входа: Telegram и/или ВК + планировщик
app/
  config.py             настройки из .env
  context.py            общие объекты (база, нейросеть, погода, каталог, заказы, рассылки)
  messenger.py          отправка в обе сети: группа/беседа, менеджеры, покупатели
  scheduler.py, jobs.py планировщик и задачи по расписанию
  keyboards.py          кнопки Telegram
  core/                 чистая логика без мессенджеров (покрыта тестами)
  services/             база SQLite, нейросеть, Open-Meteo, заказы
  handlers/             обработчики Telegram
  vk/                   ВКонтакте: API-клиент, клавиатуры, бот, перевод HTML → текст
config/                 каталог, праздники, характер бота
tests/                  тесты: python -m unittest discover -s tests -t .
```
