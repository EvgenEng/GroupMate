# GroupMate 🤖

Telegram-бот для группы: погода по Москве и области, поздравления с днём рождения,
приём заказов, приветствие новичков и ответы нейросети — в личке, в группе и в инлайн-режиме.

Работает бесплатно: погода — [Open-Meteo](https://open-meteo.com) (без ключа),
нейросеть — бесплатный тариф Google Gemini или OpenRouter.

> Идея и часть подходов вдохновлены ботом [OurMate](https://github.com/Naz1anmak/OurMate).

## Что умеет

| Функция | Как работает |
|---|---|
| 🌅 Погода утром | В 07:00 — прогноз на день: Москва подробно (утро/день/вечер), 4 направления Подмосковья кратко, советы (зонт, гололёд, ветер) |
| 🌙 Погода вечером | В 21:00 — прогноз на завтра |
| 🔔 Изменения погоды | Каждые 2 часа (9:00–21:00) сверяет прогноз с утренним: дождь/снег, гроза, ветер, перепад ≥4°, гололёд — без повторов |
| 🎂 Дни рождения | Участники пишут `/mybd 15.04`; в 10:00 бот поздравляет в группе (текст пишет нейросеть, при сбое — красивый шаблон). Владельцу — напоминание за день |
| 🛍 Заказы | Каталог с разделами → корзина → телефон и пожелания → заказ. Владелец получает уведомление с кнопками статусов, клиенту приходят обновления |
| 👋 Новички | Приветствие с кнопками «Сделать заказ» и «Что умеет бот» |
| 💛 Мягкие напоминания | Раз в неделю (по умолчанию в пятницу) и перед праздниками из `config/holidays.json` — не чаще раза в день |
| 💬 Нейросеть | В личке — на любое сообщение, в группе — по упоминанию или ответу боту. Суточный лимит на человека |
| ⚡️ Инлайн | `@бот вопрос?` в любом чате — ответ нейросети; `@бот` без текста — погода и каталог |

## Быстрый старт

### 1. Токены

1. **Бот**: [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
   Там же: `/setinline` (включить инлайн-режим) и `/setprivacy` → Disable (чтобы бот видел упоминания в группе).
2. **Нейросеть** (бесплатно): ключ [Google AI Studio](https://aistudio.google.com/apikey).
   Запасной вариант — ключ [OpenRouter](https://openrouter.ai/keys).
3. Добавьте бота в группу и **сделайте администратором** (нужно для приветствий).

### 2. Настройка

```
copy .env.example .env      (Windows)   |   cp .env.example .env   (Linux/macOS)
```

Заполните `BOT_TOKEN` и `LLM_API_KEY`. Запустите бота, напишите ему `/id` в личке —
это ваш `OWNER_ID`; напишите `/id` в группе — это `GROUP_CHAT_ID`. Впишите оба и перезапустите.

### 3. Запуск

**Windows без Docker:** двойной клик по `run.bat` (нужен Python 3.11+).

**Docker:**

```
docker compose up -d --build
docker compose logs -f
```

### 4. Проверка

Напишите боту в личку (вы — владелец):

- `/test_morning` и `/test_evening` — сводка погоды сразу уходит в группу;
- `/test_bd` — пример поздравления;
- `/catalog` — оформите тестовый заказ, вам придёт уведомление с кнопками.

## Настройка под себя

- **Каталог** — `config/catalog.json` (разделы, товары, цены, единицы).
- **Праздники** — `config/holidays.json`.
- **Характер бота** — скопируйте `config/prompt.example.txt` в `config/prompt.txt` и опишите.
- **Точки погоды** — `WEATHER_LOCATIONS` в `.env`.
- **Время рассылок, лимиты, вкл/выкл функций** — в `.env` (всё подписано).

После правки файлов в `config/` просто перезапустите бота.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/weather`, «погода» | все | погода на сегодня |
| `/tomorrow` | все | погода на завтра |
| `/catalog`, `/cart`, `/myorders` | все (в личке) | каталог, корзина, мои заказы |
| `/mybd ДД.ММ` | все | записать свой день рождения |
| `/birthdays` | все | ближайшие дни рождения |
| `/bd_add ДД.ММ Имя`, `/bd_list`, `/bd_del ID` | владелец | управление днями рождения |
| `/orders` | владелец | открытые заказы с кнопками статусов |
| `/test_morning`, `/test_evening`, `/test_bd` | владелец | проверка рассылок |
| `/id` | все | ID чата и пользователя |

## Структура

```
main.py                 точка входа
app/
  config.py             настройки из .env
  context.py            общие объекты (база, нейросеть, погода, каталог)
  scheduler.py          планировщик «каждый день в ЧЧ:ММ» / «каждые N минут»
  jobs.py               задачи по расписанию
  keyboards.py          кнопки
  core/                 чистая логика без Telegram (покрыта тестами)
    weather.py          разбор прогноза, тексты, поиск изменений
    birthdays.py        даты, ближайшие ДР, поздравления
    orders.py           каталог, корзина, тексты заказов
    holidays.py         праздники и напоминания
  services/             база SQLite, нейросеть, Open-Meteo
  handlers/             обработчики сообщений
config/                 каталог, праздники, характер бота
tests/                  тесты: python -m unittest
```
